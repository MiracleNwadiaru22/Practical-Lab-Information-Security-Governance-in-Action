# Information Security Governance in Action

## Project Overview

This repository contains my practical laboratory work for **GRC102 – Information Security Governance in Action**. The assignment focuses on developing an effective information security governance structure for **GlobalHealth Connect (GHC)**, a fictional health-tech organization.

The project examines existing governance gaps and proposes practical measures to improve accountability, risk management, security decision-making, compliance, and reporting.

## Key Areas Covered

### 1. Governance Structure

* Proposed an organizational information security governance structure.
* Defined key roles and responsibilities across management, IT, Compliance, HR, and Operations.
* Developed a **RACI matrix** to establish accountability for key security activities.

### 2. Information Security Charter

* Developed an Information Security Charter to formalize security responsibilities.
* Defined the purpose, scope, authority, roles, and key governance principles.
* Linked information security to business objectives, regulatory requirements, and customer trust.

### 3. Board Security Reporting

The project presents a Board-level view of GHC's security posture using key metrics, including:

* Phishing incidents
* Malware incidents
* Critical vulnerabilities patched
* Security awareness training completion
* High-risk security incidents

Recommendations were also provided to address the identified security concerns.

### 4. Security Steering Committee

* Developed Terms of Reference for a Security Steering Committee.
* Defined membership, responsibilities, meeting arrangements, escalation requirements, and reporting.
* Included a practical scenario involving password policy and multi-factor authentication.

### 5. Governance Maturity Assessment

The assignment assessed GHC across six governance areas:

* Policy and Documentation
* Roles and Responsibilities
* Risk Management
* Metrics and Reporting
* Training and Awareness
* Compliance

A **12–18 month improvement roadmap** was proposed to help move the organization toward a more defined and structured governance environment.

## Frameworks Referenced

The project draws on:

* **ISO/IEC 27001:2022**
* **COBIT 2019**
* **NIST Cybersecurity Framework (CSF) 2.0**

## Conclusion

This project demonstrates how effective information security governance requires clear accountability, risk-based decision-making, strong leadership, continuous improvement, and alignment between security and overall business objectives.
